# Elenga Multimedia School Android App

Android WebView app for <https://sm.dotorbits.com/>.

## Features

- Persistent Laravel login session
- File upload, camera, and downloads
- Offline screen and retry
- Android back-button navigation
- External-link handling
- Green and gold school branding

The latest APK is generated by GitHub Actions at:

`release/Elenga-Multimedia-School.apk`
